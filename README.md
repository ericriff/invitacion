# Operation: Birthday

A single-file, static RSVP invitation. Open `index.html` in a browser to preview it: drag the USB drive onto the computer to reveal the invitation, or use the **Insert drive** button. Replace the bracketed party details before sharing:

- `[Your name]`
- `[Date] · [Time]`
- `[Party address]`

The RSVP selections are handled in the browser and are not sent or stored anywhere. After confirming, guests can open the WhatsApp link to send their confirmation manually. The self-destruct is a visual effect: it clears the confirmation message after five seconds; it does not erase browser or server data.

## Free hosting with GitHub Pages

GitHub Pages can publish a static site from the root of a public repository on GitHub Free. Create a repository, upload `index.html` (and this README if you like), then open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose the default branch and `/(root)`, then save. GitHub will publish the page at the URL shown in Pages settings. See the [GitHub Pages publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
