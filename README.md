# Operation: Birthday

A single-file, static RSVP invitation. Open `index.html` in a browser to preview it. Replace the four bracketed details in the party dossier before sharing:

- `[Your name]`
- `[Date] · [Time]`
- `[Party address]`

The RSVP is handled in the browser and is not sent or stored anywhere. The self-destruct is a visual effect: it clears the confirmation message after five seconds; it does not erase browser or server data.

## Free hosting with GitHub Pages

GitHub Pages can publish a static site from the root of a public repository on GitHub Free. Create a repository, upload `index.html` (and this README if you like), then open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose the default branch and `/(root)`, then save. GitHub will publish the page at the URL shown in Pages settings. See the [GitHub Pages publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
